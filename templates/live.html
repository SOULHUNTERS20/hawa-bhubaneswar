How these numbers are made

  • Official station: real monitors run by the Odisha State Pollution Control Board for CPCB, read through OpenAQ (a non-profit that republishes government air data). Bhubaneswar has only two: Patia (zone 3) and Lingraj Mandir (zone 5). Zones 1, 2 and 4 have no official monitor at all.
  • Model: Open-Meteo, based on the European CAMS model. It estimates one value per ~40 km grid square, which is why it shows the same number for every zone.
  • AQI here uses CPCB breakpoints on PM2.5 and PM10 (the higher sub-index wins). For stations we use the latest hourly reading and for the model the 24-hour average; official CPCB AQI uses 24-hour averages and also gases like NO₂ and O₃, so treat these as PM-based AQI values.
  • If a source can't be reached, we show the last saved values with their time.
